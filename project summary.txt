3. WHAT THE APP DOES
Tripper is a collaborative road trip planner that helps users:

Create & Manage Trips - Plan multi-stop road journeys with dates, budgets, and descriptions
Interactive Maps - Use Google Maps to visualize route, add stops, and drag pins to update locations
Itinerary Building - Organize stops in sequence with arrival/departure dates, notes, ratings
Budget Tracking - Log expenses by category (fuel, food, lodging, activities, transport, other) with total/remaining calculations
Photo Gallery - Upload and organize photos per stop
Collaboration - Invite others to co-edit trips using invite codes; collaborator presence support
Activity Exploration - Search for nearby activities (nature, culture, food, entertainment)
Hotel Search - Find lodging options for overnight stops
Expense Management - Categorized spending tracking per trip
Turkish-Localized UI (login/signup text in Turkish)

6. DATABASE SCHEMA
Core Tables:

Table	Purpose	Key Fields
auth.users	Supabase auth	id, email, password_hash, metadata
profiles	User data	id (FK auth), email, display_name, avatar_url, created_at
trips	Trip records	id, owner_id, collaborator_id, title, description, start_date, end_date, total_budget, invite_code, created_at, updated_at
stops	Trip locations	id, trip_id, name, description, lat, lng, address, state, notes, place_category, rating, estimated_cost, day_number, arrival_date, departure_date, order_index, stop_type, created_by, is_favorite, created_at
expenses	Spending	id, trip_id, stop_id (nullable), category, amount, description, paid_by, created_at
photos	Media	id, stop_id, blob_pathname, caption, uploaded_by, created_at
activities	Planned activities	(inferred from types) id, trip_id, stop_id, place_id, name, address, lat, lng, category, google_types, photo_url, rating, user_ratings_total, day_number, scheduled_at, time_of_day, order_index, duration_mins, notes, estimated_cost, is_completed, created_by, created_at
trip_members	Collaboration	trip_id, user_id, role (owner/editor/viewer), joined_at
Row Level Security (RLS):

Trip members can view/edit/delete only their own trips
Collaborator model: owner + collaborator_id (single partner), or trip_members table for multi-user
Profile read is public; update restricted to own id
All tables have realtime enabled for Supabase subscriptions
Triggers:

Auto-update updated_at on trips
Auto-create profile on new auth user
7. API ROUTES/ENDPOINTS
Route	Method	Purpose	Auth
/api/trips	GET	List user's trips (with members)	Required
/api/trips	POST	Create new trip	Required
/api/budget	GET	Fetch budget items by tripId	Required
/api/budget	POST	Add expense/budget item	Required
/api/pins	POST	Create stop/pin	Required
/auth/callback	GET	OAuth redirect handler	-
Note: Most data mutations use client-side Supabase calls rather than dedicated API routes.
